# @kit/domain

Shared DTOs, stable error codes, validation helpers, and redemption-domain
types for Node and Edge consumers. It contains no SQL client or server secret.

The `@kit/domain/upload` entry point provides shared bounded body and JSON readers,
upload errors and admission gate used by Consumer BFF and central Edge handlers.

This repository currently produces private local tarballs for M5 validation. It
is not published to npm or a public Registry.
