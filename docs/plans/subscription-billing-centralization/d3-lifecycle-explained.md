# D3 生命周期策略：给业务方的简明说明

D3 不是一个技术名词，而是三个“以后发生什么”的产品规则。现在规则已经确认；删除匿名化的具体天数仍必须由法务/财务提供，代码不会擅自猜测。

## 一句话版本

- 暂停：立即停止新购买，已有有限期权益继续到期。
- 删除：保留最小账务/审计事实，个人信息按法定或财务期限匿名化。
- 归档：停止新 Checkout，保留历史订单/快照/权益，旧 Plan 不修改。

## 已确认规则

1. 暂停是独立的购买闸门：新的付费 Checkout 立即拒绝；已有有限期权益和已付款订单继续按原流程处理。
2. 删除只最小化个人字段和可识别审计字段；订单、金额、结算、Grant、快照等事实保留。`private.account_retention_policy` 必须提供天数、来源与依据，未配置则清理任务失败关闭。
3. Plan 归档是不可变终态：新 Checkout 拒绝，历史订单/价格快照/已有权益保留；新条款必须创建新 Plan。
