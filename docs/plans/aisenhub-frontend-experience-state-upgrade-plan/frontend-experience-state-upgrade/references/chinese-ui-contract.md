# 中文优先 UI 合同（FE-R1）

本合同适用于 Admin、Consumer、公开认证/套餐页面及 Registry 安装产物。用户已明确反馈英文影响理解，本期默认简体中文，不把中文适配延期到未来国际化专题。英文切换、多语言路由和翻译服务不是本期新增目标。

## 1. 展示与技术标识边界

- 导航、标题、表头、按钮、字段标签、帮助、校验、确认框、空态、错误、加载/重试、Toast、无障碍名称和屏幕阅读器播报默认中文。
- 技术标识保持原值：API、SDK、URL、ID、UUID、HTTP 状态、JSON、MIME、Provider/品牌名称、代码、命令、路径、错误码及数据库枚举。用户填写的名称、文件名、原始审计内容不擅自翻译。
- 中文主文案说明意义和下一步；必要英文原值放“技术详情”或复制区。不得改动 wire DTO、枚举、operation_id、Header、URL、幂等 key 或 Auth scope 来实现翻译。
- MFA 首次出现可写“多重身份验证（MFA）”，后续按场景用“身份验证”；API Key 用“API 密钥”。不要求用户理解 entitlement、projection、receipt、unknown outcome 才能操作。
- 未知错误显示“操作未完成，请查看当前状态或稍后重试”等经过操作分类的中文 fallback，不能直接输出 Error.message/内部 code；未知写入结果必须保留不确定性，不能统一称为失败。
- 技术详情保留脱敏 request ID/code；错误服务返回的敏感内容不得因翻译而进入日志或提示。

## 2. 统一术语

| 原概念 | 主界面中文 | 说明 |
|---|---|---|
| Overview | 概览 | 全局与平台标题明确范围 |
| Platforms / Platform Workspace | 平台 / 平台管理 | Workspace 只是页面组织，不新增领域模型 |
| Accounts | 平台账户 | 区分全局身份 |
| Entitlements / Plans / Subscriptions | 权益 / 套餐 / 订阅 | 不把套餐展示当已授予权益 |
| Redemption Batches | 兑换码批次 | 单码叫兑换码 |
| Files / File Policy | 配置文件 / 文件策略 | 策略在配置文件范围 |
| Operations / Audit | 运维任务 / 审计记录 | 不把请求接受当完成 |
| Settings / Origins / API Keys | 设置 / 来源地址 / API 密钥 | 来源地址帮助中解释 Origin 用途 |
| Security / Danger Zone | 安全设置 / 高风险操作 | 不仅依赖红色 |
| active / suspended / closed | 正常或启用 / 已暂停 / 已关闭 | 按资源类型映射，禁止全局机械替换 |
| pending / deleting / deleted | 等待处理 / 正在删除 / 已删除 | 原始枚举仅技术详情显示 |
| accepted | 请求已受理，正在处理 | 不是“删除成功” |
| unknown_outcome | 结果暂未确认 | 提供“查看当前状态”；不诱导重复提交 |
| recent MFA required | 请再次验证身份后继续 | 不显示模糊“权限错误” |
| session retry required | 会话已恢复，请重新确认并提交 | 不声称已自动提交 |
| empty / filter empty | 暂无记录 / 没有符合条件的记录 | 筛选空态提供清除条件 |
| delivery confirmed | 交付已确认 | 区分仅复制、已保存和服务端确认 |

## 3. 实现与排版

- Phase 01 建立轻量、可类型检查的中文文案与状态映射约定；共享组件接收标签/文案，不硬编码领域英文。已有适用 i18n 能力可复用，不为中文默认新增大型框架或翻译服务。
- Admin 与 Consumer 可采用不同详细程度，必须共用关键术语；禁止页面各自定义同一错误的不同业务含义。
- 根页面设置正确的简体中文语言标记。字体使用中文系统回退，避免依赖必须联网下载的字体；ID/code 区域使用等宽字体。
- 中文按钮、表头和帮助文字实际在 320/375/390/768 与桌面测试；不靠缩小字号塞入文字。中文自然换行，URL/长 ID 安全断行并可完整复制；不能截断关键风险说明。
- 日期使用明确 locale/timezone 格式，标明时区，避免含糊的月/日顺序；传输仍 UTC ISO。数字、字节/容量单位统一，说明 KiB/MiB 等单位，不改额度或舍入后的授权判断。
- Toast、Dialog、Command、分页、日期控件、上传状态等复用组件的默认英文也在核查范围。Command 支持中文导航词，必要的英文缩写可作为搜索别名。
- 测试优先使用稳定 data-test/语义角色，不把中文翻译成接口字段，也不为让旧英文 locator 通过而保留不可理解的英文主 UI。

## 4. 阶段验收

- Phase 01：Audit、Shell、空/错/加载态中文样例与术语定稿，中文字体、语言标记、控件默认文案验证。
- Phase 03：账户关闭、密钥创建/撤销、再次验证、结果未确认、一次性明文提示全部中文可理解。
- Phase 04～06：资源页、筛选、运维任务与技术详情采用同一术语；所有风险后果可用中文理解。
- Phase 07：Consumer 的登录/注册/找回密码/更新密码/套餐和受保护页面全部纳入；独立安装产物也须中文可用，不允许以“范围过大”延期。
- Phase 08：人工走完中文主流程，扫描残留英文并逐条分类为必要技术标识、用户内容或待修缺陷；自动文本扫描不等于通过。校验中文 aria-label/live region、窄屏排版、日期数字及英文原值复制。FE-V13～16 记录用例、截图（脱敏）、代码 SHA 和结果。
