# List + Detail / Inspector

适用于平台、账户、订单、审计事件、Feedback、Config 等“集合定位对象 → 查看详情”的任务。

## 结构

1. 明确当前 Global/Platform scope。
2. 提供必要搜索/筛选/排序和结果数量语义。
3. 列表或表格展示可扫描的一级信息和真实状态。
4. 选择对象后在 route、Sheet、Inspector 或详情页呈现二级信息。
5. 关闭/返回时尽量保留筛选、滚动和触发焦点。

## 状态

至少区分：

- 尚未加载；
- 读取失败；
- 无访问权；
- 真正没有对象；
- 有对象但当前筛选无结果；
- 后台刷新失败但仍有最后可信数据；
- 对象被删除/失效或 URL 目标不存在。

这些状态不能都折叠成一个 Empty State。

## URL 与作用域

适合恢复/深链的 selected id、scope 和筛选可进入 URL，但不得放 Secret 或私密正文。切换 Platform 时不能携带其他平台的实体 ID；具体映射遵循 `REQ-ADM-002` 和当前路由架构。

## 可达性

Table 横向滚动区域有可访问名称且可键盘滚动；行本身不是必须 clickable。选择态有非颜色语义；详情关闭时恢复到合理触发入口，触发对象已消失时回到后续合理位置。
