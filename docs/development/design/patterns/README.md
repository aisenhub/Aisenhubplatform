# UI Patterns

Pattern 是跨页面重复出现的**任务组织方式**，不是复制页面模板。它帮助 Feature 组合标准组件，同时让数据、权限、保存和领域状态继续由真实 owner 负责。

## 主题

- [模式契约](contract.md)
- [List + Detail / Inspector](list-detail.md)
- [Settings / Explicit Save Form](settings-form.md)
- [Admin Workspace / Toolbar](workspace.md)
- [Authoritative Results Reading](results-reading.md)
- [显式保存表单样例](assets/explicit-save-form.md)

Pattern 不规定所有页面都有 Card、三列布局、固定 CTA 数量或同一种保存机制。只有真实重复结构稳定后才考虑进一步提取组合组件。
