# 图标

图标用于快速识别动作和对象，不替代文本语义、状态真值或可访问名称。

## 通用规则

- 同一动作在同一产品中使用稳定图标语言；普通 UI 图标必须优先来自 Product Adaptation 指定的标准图标库，不能由 Feature 随机自绘 SVG/PNG 形成第二套视觉语言。
- 普通图标颜色消费语义前景；不要在每个 SVG 内维护独立主题颜色。
- 图标大小随控件用途，视觉尺寸与可点击区域分开。
- 图标按钮必须有可访问名称；Tooltip 只是辅助说明，不是唯一名称。
- 装饰图标对辅助技术隐藏；状态图标同时提供文字/ARIA 等非颜色线索。
- 不用 emoji 或随机自定义 SVG 代替已有稳定图标；品牌 Logo、真实业务图片和标准库确实无法表达的专业图形属于例外，必须记录用途、来源/许可和 owner，并且不能扩展成平行通用 icon set。
- 加载/警告/删除等图标必须与真实状态和动作一致，不能用“魔法/机器人”泛指所有 AI 或自动化能力。
