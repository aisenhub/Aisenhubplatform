# 文字排版

排版用于建立信息层级、扫描效率和连续阅读体验。具体字体、字号和字重由 Aisenhub Product Adaptation 与运行 Theme 决定；通用层维护角色和验证方法。

## 语义角色

建议至少能表达：

- page-title：页面一级标题；
- panel-title：主要面板/Inspector 标题；
- section-title：局部分组标题；
- control：按钮、菜单项等控件文字；
- label：字段、表头和紧凑说明；
- body：一般内容；
- reading：较长说明、正文、政策/审计阅读；
- caption：元信息；
- identifier/code：ID、request id、代码或逐字符辨认内容；
- numeric：需要对齐时启用 tabular-nums，而不是把所有数字强制改为代码字体。

## 内容与层级

- 同用途文本沿同一角色，不在每个组件任意自选字号。
- 标题层级由语义、字重、空间和颜色共同建立，不要求所有层级都有不同字号。
- 中文默认保持自然字距；西文大写或紧排策略不能机械套到中文。
- 长标题、错误、对象名称允许换行或提供完整查看方式；必要信息不能为了整齐被不可恢复地截断。
- 连续阅读按语言和字体验证行长与行高。65–75ch 只能作为拉丁正文的起点，不是中文或所有控件的硬阈值。

## 缩放与语言

不禁用页面缩放。文字放大、窄视口、长中英文、混排数字和用户间距覆盖后，主要任务与错误仍应完整可用。界面语言变化不能通过整体缩小字号来“塞回”布局。
