# 图标控件契约

## 图标按钮

- 实际交互元素必须是标准 Button 或具有等价语义/键盘行为的控件，不能让 SVG 本身承担点击。
- 图标按钮有清楚的 accessible name；Tooltip 可补充解释，但不是唯一名称。
- 图标是装饰内容时对辅助技术隐藏，避免按钮名称被重复朗读。
- toggle/pressed 等状态使用真实 `aria-pressed`、`aria-expanded`、`aria-selected` 或组件模型，不只替换 SVG。
- disabled/focus/busy 由外层控件管理，不在图标内部再做第二套状态。

## 带文字的图标控件

文字已经提供动作名称时，装饰图标不应重复朗读。图标位置（start/end）属于有限组件能力；不要在业务页面通过绝对定位重新拼按钮内部布局。

## 尺寸与点击范围

视觉 icon size 与 target size 分开。紧凑桌面控件可以使用较小图形，但必须满足适用的指针目标和可达性要求；扩大热区不能覆盖相邻动作。

## 状态图标

成功、警告、错误和 unknown 图标必须配合文字/结构语义，不能仅靠绿色勾/红色叉表达结果。Loading spinner 只用于真实 busy，不代表完成百分比。
