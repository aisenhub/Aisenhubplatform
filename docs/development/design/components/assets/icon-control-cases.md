# 图标控件说明用例

自编场景素材，用于评审，不是生产实现证明。

| 场景 | 可观察结果 |
| --- | --- |
| 关闭右侧 Inspector | 关闭图标位于有名称的按钮中；键盘可触发，关闭后焦点回到合理触发入口 |
| Sidebar 折叠/展开 | 图形与实际状态同步，有 `aria-expanded` 或等价语义，不只换 SVG |
| 带图标的“重试”按钮 | 名称由文字提供，图标隐藏于辅助技术；请求未结束时 busy/disabled 与真实行为一致 |
| 密集表格行操作 | 图标目标不与相邻动作重叠；键盘、触控与 Tooltip 不是唯一发现路径 |

实际评审必须操作真实组件并记录焦点、键盘和状态；样例本身不证明任何 `@kit/ui` 组件已通过。
