## 故障点与修复

- maintenance worker 使用稳定 worker id，避免每个 HTTP 请求生成新 lease owner 导致旧 fence 误判。
- 历史匿名化补齐 domain owner 对 `audit_logs` 的最小更新权限；`job_executor` 不获得该表更新权限。
- Auth 删除前通过受控 `deletion_job_auth_prepare` 脱离 `platform_accounts.user_id` 外键引用，并将 identity lifecycle 外键改为受控级联，随后才调用 server-only Auth Admin adapter。
- 所有修复均保留在 pgTAP、worker 单测和 G4-L 探针中，未通过放宽 RLS 或删除审计来掩盖失败。
