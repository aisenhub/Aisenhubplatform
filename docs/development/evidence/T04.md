## 结论与交接

中央 Account API 先用 Auth `/auth/v1/user` 验证 bearer，并比对 Auth subject 与 JWT subject；数据库 helper 再绑定当前 `session_id`。AAL2 管理员可取得不超过五分钟的 proof，高风险写操作再次校验该 proof。logout 先撤销 Auth session，Cookie 只在撤销成功后清除。Supabase 不支持以项目角色直接读取受保护的 `auth` schema，因此 MFA/AAL2 由 Auth HTTP 边界验证，数据库不扩大 Auth 表权限。
