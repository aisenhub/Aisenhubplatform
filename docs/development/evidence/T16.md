## 结论

T16 的 Consumer/BFF 安全边界已独立交付，但完整 G2-L 纵向验收保持部分完成。`template-preview` 提供同源 BFF 路由，使用每请求的 server SDK 调用中央 Account API；平台Key只来自服务端配置，浏览器构建不包含后端凭据标记。中央 Account HTTP 实现和真实浏览器登录回调尚未在本批交付，未将测试桩计为真实链路通过。

## 交付

- `packages/account-server/src/index.ts`：中央 Account API 的 server-only typed client，统一平台Key、Bearer、If-Match、JSON和错误映射。
- `apps/template-preview/app/api/v1/[...path]/route.ts`：plans、principal、activate、profile、preferences的同源BFF路由；每请求client、no-store、ETag、Origin/CSRF和默认拒绝。
- `apps/template-preview/app/pricing/page.tsx`：公开Pricing入口，不暴露Key、不强迫登录。
- `apps/template-preview/app/api/v1/[...path]/route.test.ts`、`packages/account-server/tests/client.test.ts`：BFF与SDK边界测试。
