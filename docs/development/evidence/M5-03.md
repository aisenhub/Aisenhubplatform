## 本批交付

- 增加 Admin 资源导航，覆盖总览、平台/账户、计划/批次、订阅、文件、删除任务和审计入口。
- 增加 Subscription Operations 页面：只读订阅投影，受控 command，必填脱敏 reason、单次 `operation_id`、显式确认、409 冲突提示和 MFA 过期提示。
- 增加 Audit Log 页面：只读筛选与刷新；后端仍为 `contract-only` 时展示明确不可用状态，不伪造空结果。
- 完善 Entitlements 批次流程：创建 `pending_delivery`、单次显示明文码和 receipt、显式确认交付后清除明文状态；不提供重新导出。
- 计划页接入同一 `admin_plan_upsert` 入口的归档、默认 Free 设置/清空动作；默认计划归档由 UI 前置阻止并保留后端约束错误。
- 平台页补充 Key 新建→部署确认→撤旧交互，以及账户 suspend/restore/close 的必填 reason；部署确认由持久化字段、受控 SQL wrapper、Audit 事件和 Admin API 支撑。
- 订阅页读取和 command 均显式携带 `platform_id`，与 Account API 的跨平台范围校验一致。
- 文件页增加服务端游标分页、状态筛选，并对 `unknown`/`deleting` 显示不释放预算、不绕过状态机的警示。
- 新增共享 `AdminFilterInput`，统一平台、Origin、Key、账户、审计、文件、删除任务、Plan 和兑换批次的筛选输入与可访问标签；已完成的平台、Origin、Key、账户和文件资源服务端 `q` 搜索，仍保留当前页本地即时筛选。
- 现有平台、权益、文件、删除任务页统一接入资源导航。
