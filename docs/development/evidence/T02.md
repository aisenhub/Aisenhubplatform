- 保留根 `AGENTS.md`、`docs/`、`.git` 历史和原有 README，并导入固定上游 LICENSE、workspace、lock、Turbo、Oxlint/Oxfmt、tooling 和必要基础 packages。

- `apps/web` 没有原样保留；仅以固定上游配置为参考建立 `apps/admin`，提供 `/admin/login`、`/admin` 和根路径重定向。登录、会话、MFA 和授权明确留给后续任务。
- `apps/template-preview` 是独立 Consumer 空壳，提供 `/` 和 `/login`，不依赖 Admin 应用或 Starter 账户包。
- 删除根 `postinstall=manypkg fix`、危险 `git clean -xdf` workspace 脚本、自动 fix 快捷命令和上游 `supabase:deploy` 入口；保留只读 lint/format/typecheck/build 命令。
- `apps/web/supabase` 迁为根 `supabase` 本地配置参考；删除 `public.accounts` Starter migration 和 seed，不创建生产领域迁移。
- 根 `supabase/config.toml` 使用项目本地标识 `aisenhub-platform-local`；CLI catalog 固定为 `2.111.0`，避免后续范围版本漂移。
- 未复制上游 `.env*` 文件；两个应用只提交脱敏 `.env.example`。保留 MIT LICENSE，并新增 `THIRD_PARTY_NOTICES`。
- 根 `tsconfig.json` 的 `moduleResolution` 调整为 TypeScript 7 支持的 `bundler`。
- 上游 Next 16.3.0 默认 Turbopack 在 Windows 当前依赖布局下出现内部模块解析错误；两个应用的 build script 固定为 `next build --webpack`。未升级 Next、React 或 lock 中其他依赖。
