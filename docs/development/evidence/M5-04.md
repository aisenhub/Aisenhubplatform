## 本批交付

- 增加 `registry/manifest.json` 和 `registry/templates.json`，固定 Local preview 的 Node/pnpm/Next 版本、SDK 兼容范围、模板清单和 M5-02 校验和来源。
- template-preview 补齐 Signup、Forgot password、Reset password 页面及同源服务器端 Auth 路由；OAuth callback、Pricing、Profile/Preferences、Subscription/Redeem、Files、UserMenu 继续复用现有 BFF。
- 新增 Auth 路由只使用 publishable key/request-scoped client，session 通过 HttpOnly cookie 管理；不把 service role、数据库连接或 Platform Key 放入浏览器代码。
- Registry 验证脚本检查模板覆盖、路由清单和敏感配置边界。
