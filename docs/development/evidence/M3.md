## 边界与后续

- 计划归档会阻止新 Grant；历史 Grant 不删除。默认 Free 可在同一函数调用中切换或清空，返回值显式区分 `false` 与 SQL `NULL`。
- 兑换码明文只作为生成结果返回给受控交付层；数据库只接收 HMAC、版本和前后缀 mask。生成器使用拒绝采样避免字节取模偏差。
- M3-03 的 Local HTTP adapter 已完成；OpenAPI 中已交付的 M3 路径标为 `local-only`，未交付资源仍保持 `contract-only`。托管环境与 T04 logout 即时失效合同仍需后续环境验收。
