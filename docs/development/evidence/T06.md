# T06 受控上传与真实字节边界探针

## 结果

T06 验收：PASS（Local Node/fake Storage）。真实 Edge host、真实 Storage provider 的取消和迟到写入留给 T17/G4-S。

## 实施

- 新增 `tests/spikes/upload/controlled-receiver.mjs`，只实现隔离测试接收器和 fake Storage adapter，不创建生产文件表、Storage bucket 或浏览器直传入口。
- body 读取前取得并发名额；超过上限、声明长度超过上限或声明与真实字节不一致时，Storage 调用保持 0。
- 收齐前使用有界缓冲；只有收齐且实际字节未超限才调用 Storage。`Content-Encoding` 不得把原始体积检查变成信任声明。
- provider timeout 返回 `unknown`，并保留已发生的 Storage 调用/预算占用事实；不把超时当作可释放失败。

## 实际验证

| 用例/检查 | 结果 | 证据 |
|---|---|---|
| 1MiB | PASS | 恰好 `1,048,576` 字节，Storage 调用 1 |
| 1MiB+1 | PASS | 实际超限，Storage 调用 0 |

## 边界

本探针证明的是接收器状态和调用边界，不声称 fence 能取消外部 Storage 操作；事务 fence、`unknown` 持久化和恢复任务必须由 M1/M4 设施实现。没有向浏览器发放签名上传 URL。
