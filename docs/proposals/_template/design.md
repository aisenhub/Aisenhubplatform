# 模块优化设计模板

模板用途：复制到具体优化目录后填写，不代表实际优化项目。

状态：Proposed

关联：[总计划](plan.md)

## 背景与当前问题

填写问题、影响范围及对应源码位置，链接当前 architecture 文档。

## 目标与范围

填写希望改善的行为、可验证目标，以及明确排除的内容。

## 当前架构

概述与本次优化有关的真实调用链；引用现有架构，避免复制完整说明。

## 目标架构

描述模块职责、依赖、数据流和关键流程。必要时添加架构图，并明确哪些内容尚未实现。

## 接口、数据与配置

列出受影响的 API、共享类型、数据库迁移、配置和消费者；说明兼容与迁移要求。

## 风险与取舍

记录权限、并发、性能、失败恢复及替代方案；重要长期决策按需建立 ADR。

## 验收条件

定义能证明目标达成的行为、指标及所需环境。

## 待确认项

列出影响设计或执行的未决问题。
